# Six-week internship mapping

## Week 1 — research and requirements

Document the reference interaction without copying assets, define acceptance
criteria, establish the `main` / `develop` / `feature/*` workflow, and create
issues for VR, API, database, accessibility, security, and deployment.

## Week 2 — WebGL and backend foundation

Research equirectangular projection and Pannellum lifecycle behavior. Model
tours, scenes, category taxonomy, typed hotspots, media, administrators, and
privacy-minimized analytics in Prisma. Start MySQL with Docker and implement validated
public route handlers.

## Week 3 — interface and navigation

Build the welcome screen, responsive shell, scene cards, bilingual dictionary,
information panel, modal focus behavior, and Leaflet map. Synchronize URL,
navigation, map markers, and selected-scene copy.

## Week 4 — immersive interaction

Integrate Pannellum directly, add typed DOM hotspots, transition locking, preview
preload, browser-history restoration, audio lifecycle rules, WebGL fallback, and
administrator coordinate picking.

## Week 5 — quality

Add unit, component, API-helper, and Playwright coverage. Test desktop, portrait,
and landscape layouts; repeated scene changes; keyboard navigation; invalid
media; throttling; draft filtering; and authentication expiry. Profile previews,
bundle loading, and blur effects on mobile.

## Week 6 — handoff

Finish architecture, database, API, and panorama documentation. Capture original
screenshots, validate CI and production build, deploy with managed MySQL, prepare
an internship report, and demonstrate each acceptance criterion in a final
presentation.

Each week should end with a reviewable pull request, a short retrospective, and
updated evidence in the internship report rather than an unverified percentage
claim.
